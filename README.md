# Anti-AFK Tool

A simple AutoHotkey script to prevent getting kicked for inactivity in games.

## Features

- Simulates random key presses (W,A,S,D)
- Random jumping
- Random mouse movements
- Intelligent user input detection (pauses when you're active)
- Focus Roblox window automatically
- System tray support with hide button

## How to Use

1. Download and install [AutoHotkey](https://www.autohotkey.com/) if you don't have it
2. Download `AntiAFK.ahk`
3. Double-click to run
4. Configure settings and click "Start"
5. Use "Hide to Tray" to keep it running in background

## Settings

- **Interval**: Time between anti-AFK actions (seconds)
- **Initial Delay**: Time before input detection starts (seconds)
- **Resume Delay**: Time of inactivity before resuming (seconds)

## Notes

- The tool automatically pauses when you use your keyboard or mouse
- Resumes automatically after your set delay
- Click "Hide to Tray" to minimize to system tray
